# US-004: View live market overview, Order Book, and Tape

## Story
**As a** Guest or Trader
**I want** to browse all Assets and view a selected Asset's live aggregated Order Book and Recent Trades Feed (Tape)
**so that** I can observe real-time liquidity, the Bid-Ask Spread, and price discovery.

## Basic flow
- **BF-01:** User opens the market view and sees all 5 seeded Assets with Ticker, company name, Last Traded Price (or Initial Reference Price before the first Trade), and rolling Volume.
- **BF-02:** User selects an Asset (e.g., `AAPL`).
- **BF-03:** System displays the live aggregated Level 2 Order Book (Bids highest-first, Asks lowest-first, total resting quantity per Price Level, and Bid-Ask Spread) and the live Recent Trades Feed (`price`, `quantity`, `timestamp`, `aggressor_side`).
- **BF-04:** As orders rest, cancel, or match on `AAPL`, System pushes live updates to the view automatically.

## Alternate flows
- **AF-01** (from BF-02): If the user requests a Ticker that does not exist on the exchange, then System indicates the Asset was not found. → End.

## Acceptance criteria
- **AC-01** (BF-01, SRS/BR-13): Given `AAPL` has an Initial Reference Price of `$220.00` and zero Trades, when a Guest views the Asset list, then `AAPL` displays `$220.00` and Volume `0`.
- **AC-02** (BF-03, SRS/BR-04): Given `AAPL` has two resting Bids of `30` and `20` shares at `$219.90` and one resting Ask of `40` shares at `$220.10`, when a Guest views `AAPL`'s Order Book, then the Best Bid shows `$219.90` with total quantity `50`, the Best Ask shows `$220.10` with total quantity `40`, and the Bid-Ask Spread is `$0.20`.
- **AC-03** (BF-04, SRS/BR-13): Given a Limit Buy rests at `$219.95` without matching, when the Order Book updates, then Best Bid updates to `$219.95` while Last Traded Price and Volume remain unchanged.
- **AC-04** (BF-03, BF-04, SRS/BR-13): Given an incoming Buy order matches `10` shares at `$220.10`, when the Trade settles, then the Tape appends `{ price: $220.10, quantity: 10, aggressor_side: BUY }`, Last Traded Price becomes `$220.10`, and Volume increases by `10` (counted once).
- **AC-05** (AF-01): Given a Guest requests Ticker `UNKNOWN`, then System returns a not-found error.

## Out of scope
- Individual order-by-order Level 3 Order Book attribution (Trader identities are never exposed publicly).
