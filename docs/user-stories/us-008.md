# US-008: Cancel an active order

## Story
**As a** Trader
**I want** to cancel any of my active resting orders
**so that** it is removed from the Order Book and my unfilled Reserved Cash or Shares are immediately returned to Available.

## Pre-conditions
- **PRE-01:** Trader is signed in and owns an order in state `OPEN` or `PARTIALLY_FILLED`.

## Basic flow
- **BF-01:** Trader requests cancellation of a specific order ID.
- **BF-02:** System assigns the next per-Asset Sequence Number, verifies ownership and active state, and removes the order from the Order Book.
- **BF-03:** System releases all remaining unfilled reservations (`remaining_qty × limit_price` for Buy, or `remaining_qty` shares for Sell) back to Available, marks the order `CANCELLED`, and notifies the Trader.

## Alternate flows
- **AF-01** (from BF-02): If the order is already `FILLED`, `CANCELLED`, or `REJECTED` (including when a Trade fills it right before the cancel is sequenced), then System rejects the cancellation without reversing any Trade. → End.
- **AF-02** (from BF-02): If the order belongs to a different Account or does not exist, then System rejects the request as forbidden/not found. → End.

## Acceptance criteria
- **AC-01** (BF-02, BF-03, SRS/BR-09, SRS/BR-10): Given `alice` has a `PARTIALLY_FILLED` Limit Buy for `10` `AAPL` at `$200.00` (`4` filled, `6` remaining, `$1,200.00` Reserved Cash), when `alice` cancels it, then the order is removed from the Order Book, `$1,200.00` moves back to `alice`'s Available Cash, the `4` filled shares remain immutable, and the order status becomes `CANCELLED`.
- **AC-02** (AF-01, SRS/BR-09): Given `alice`'s order was already `FILLED` before her cancel command was sequenced, when the cancel executes, then the cancel is rejected and her filled shares and cash remain unchanged.
- **AC-03** (AF-02): Given `bob` attempts to cancel `alice`'s active order, then System rejects the request and `alice`'s order remains `OPEN`.

## Out of scope
- Bulk "cancel all orders across all assets" button (can be added later).
